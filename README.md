# The 3 AM Excuse — Hardware Wallet

Entry for the make.fun competition [The 3 AM Excuse](https://make.fun/c/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878): one line, under 200 characters, in the voice of a hardware wallet that will not sign a transaction at 3 AM.

> At 3 AM I don't sign — I count my owner's bad decisions instead, and tonight's list is already full.

## How to run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), byte-for-byte identical to `entry.txt` in this repository.
